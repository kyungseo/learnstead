# 작성 원칙

## 독자부터 정한다

각 자료는 첫 부분에서 대상 독자, 얻을 결과, 필요한 사전 지식과 범위를 밝힙니다. 처음 접하는 독자를 대상으로 할
때는 전문 용어를 처음 쓰는 자리에서 설명하고, 더 깊은 내용은 `🔧 한 단계 더` 블록으로 분리합니다.

## 가장 짧은 유용한 경로를 먼저 둔다

독자가 실행하려는 자료라면 긴 개념 설명보다 첫 성공 경로를 앞에 둡니다. 다만 안전 조건과 필수 전제는 명령보다
먼저 보여 줍니다. 선택지와 내부 원리는 첫 성공 이후에 설명해도 됩니다.

## 사실과 검증 상태를 구분한다

본문에서는 다음 표현을 사용합니다.

| 표기 | 의미 |
| --- | --- |
| `원리` | 특정 제품 버전보다 오래 유지되는 구조·수학·물리 설명 |
| `실행 검증 · YYYY-MM-DD` | 적어 둔 환경에서 명령을 실제 실행하고 성공 조건을 확인함 |
| `부분 검증 · YYYY-MM-DD` | 전체 경로 중 명시한 일부만 실제로 확인함 |
| `문서 확인 · YYYY-MM-DD` | 공식 문서나 공식 발표를 확인했지만 직접 실행하지는 않음 |
| `자료 확인 · YYYY-MM-DD` | 공개 자료를 확인했지만 1차 출처 또는 직접 실행으로 확정하지 못함 |
| `미검증` | 현재 직접 확인하지 못했으며 독자가 그대로 신뢰해서는 안 됨 |
| `해석` | 여러 근거를 바탕으로 저자가 정리한 판단 |

웹에서 읽은 사실을 `실행 검증`으로 표현하지 않습니다. `자료 확인`은 선택의 출발점일 뿐, model·hardware 구매나
운영 결정의 최종 근거로 사용하지 않습니다. 날짜는 무엇을 확인했는지 알 수 있도록 각 자료의
`SOURCES.md`와 `VALIDATION.md`에 연결합니다.

## 바뀌는 정보에는 유효기간을 드러낸다

모델 목록, 도구 사용법, 하드웨어 사양, 가격과 라이선스는 달라질 수 있습니다. 이런 정보에는 확인일과 직접 연결된
출처를 적고, 오래된 자료를 다시 확인해야 하는 조건을 `CHANGELOG.md` 또는 본문에 남깁니다.

## 페이지 날짜보다 검증 날짜를 남긴다

독자용 페이지 머리말에는 작성일이나 마지막 수정일을 반복해서 표시하지 않습니다. 문서 전체의 날짜만으로는 어떤
설명과 명령이 지금도 유효한지 판단할 수 없기 때문입니다.

- 변할 수 있는 주장에는 `실행 검증`, `문서 확인`, `자료 확인` 표기와 확인일을 함께 둡니다.
- 직접 실행한 환경과 결과는 자료의 `VALIDATION.md`에 기록합니다.
- 최초 공개일과 독자에게 영향을 주는 변경일은 자료별 `CHANGELOG.md`에 기록합니다.
- Git 이력은 편집 과정을 추적하는 수단으로 사용하되, 내용의 유효성을 대신하는 근거로 삼지 않습니다.

## 한국어로 설명하고 식별자는 보존한다

본문과 운영 문서는 한국어 문장으로 씁니다. 다만 `model`, `memory`, `runtime`, `data`처럼 기술 문맥에서 널리 쓰이고
검색에도 도움이 되는 기본 용어는 영어를 그대로 사용할 수 있습니다. 처음 접하는 독자가 문맥만으로 뜻을 알기
어렵다면 첫 등장 위치에서 짧게 설명하고, 같은 자료 안에서는 표기를 일관되게 유지합니다.

명령어, option, API path, model ID, 파일명과 제품명은 검색과 재현에 필요한 식별자이므로 원문을 유지합니다. 모든
영어 용어를 번역하는 것 자체를 목표로 삼지 않습니다.

## 공개 경계를 지킨다

개인 장비의 절대 경로, 고객·내부 프로젝트 식별자, 비공개 저장소 주소, review transcript와 비밀값을 자료에 넣지
않습니다. 외부 사례가 꼭 필요하면 공개된 1차 출처만 직접 연결하고, 출처가 주장하는 범위를 넘겨 일반화하지 않습니다.

## 변경 기록의 역할을 나눈다

- 저장소 root `CHANGELOG.md`: 콘텐츠 유형, 작성 정책, 카탈로그와 저장소 구조의 변화
- 각 자료의 `CHANGELOG.md`: 독자가 읽고 실행하는 내용, 지원 경로, 수정·정정과 검증 범위의 변화

공개 전 작성 과정은 changelog에 옮기지 않습니다. 최초 공개일을 초판 날짜로 기록하고 이후 독자에게 영향을 주는
변경부터 누적합니다.
