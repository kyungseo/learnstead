# 콘텐츠 유형

Learnstead의 자료는 독자가 무엇을 얻으려는지에 따라 가이드, 튜토리얼, 실습으로 나뉩니다. 한 자료가 모든 역할을
떠안지 않도록 주된 목적 하나를 먼저 정합니다.

## 한눈에 구분하기

| 유형 | 독자의 질문 | 기본 흐름 | 필수 검증 |
| --- | --- | --- | --- |
| 가이드 | “무엇인지 이해하고 내 상황에 맞게 선택하려면?” | 개념 → 선택 기준 → 권장 경로 → 참고 절차 | 주요 주장과 예시 경로의 근거·검증 상태 |
| 튜토리얼 | “이 결과를 처음부터 끝까지 어떻게 만들지?” | 준비 → 순서가 있는 단계 → 결과 확인 → 복구 | 하나 이상의 명시된 환경에서 전체 경로 재현 |
| 실습 | “이 조건에서 직접 판단하고 실패까지 확인하려면?” | 시나리오 → 과제 → 관찰 → 판정 → 초기화 | 고정된 입력·기대 결과·negative case·reset 절차 |

## 가이드

가이드는 개념과 선택 기준이 중심입니다. 여러 경로를 비교할 수 있지만, 초급자용 자료라면 가장 짧은 성공 경로를
먼저 보여 줍니다. 독자는 전부 읽지 않아도 자기 상황에 필요한 문서로 이동할 수 있어야 합니다.

필수 구성:

- 목적, 대상 독자, 범위와 다루지 않는 것
- 처음 읽는 사람을 위한 가장 짧은 경로
- 선택 기준과 경로별 전제
- 변하기 쉬운 정보의 확인일과 출처
- `CHANGELOG.md`, `SOURCES.md`, `VALIDATION.md`

## 튜토리얼

튜토리얼은 정해진 결과를 한 경로로 완성하는 데 집중합니다. 선택지를 많이 나열하기보다 왜 이 경로를 쓰는지 짧게
밝히고, 독자가 만나는 순서대로 경고와 성공 판정을 배치합니다.

필수 구성:

- 지원 환경과 사전 준비
- 그대로 실행할 수 있는 순서가 있는 단계
- 단계별 예상 결과와 최종 성공 판정
- 흔한 실패와 원상복구 방법
- 전체 경로의 실행 환경·실행일·결과

## 실습

실습은 설명을 따라 하는 데서 끝나지 않고 독자가 관찰하고 판정하게 합니다. 실행 파일이나 고정된 fixture가 포함될
수 있으므로 재현성과 초기화가 콘텐츠의 일부입니다.

필수 구성:

- 학습 목표와 완료 조건
- 고정된 시나리오, 입력과 환경
- 정상 경로와 하나 이상의 실패 경로
- 관찰할 값, 기대 결과와 판정 기준
- 반복 실행을 위한 reset·cleanup 절차
- fixture와 도구의 버전 또는 고정된 revision

실행 artifact를 독립적으로 내려받거나 특정 버전으로 재현해야 하는 실습이 생기면 그때 tag와 GitHub Release 도입을
검토합니다. 현재는 저장소와 개별 자료의 변경 기록만 사용합니다.
