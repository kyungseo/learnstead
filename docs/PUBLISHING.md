# 가이드에서 블로그와 소셜로 이어지는 발행 절차

한 학습 자료를 공개하는 일과 그 자료를 소개하는 블로그 글을 게시하는 일을 연결합니다. 가이드가 원문과 실행 근거를 소유하고, 블로그는 독자가 왜·어디서 시작할지 안내합니다. 소셜은 사용자가 직접 게시할 선택적 초안입니다.

새 가이드의 발행 작업은 관련 블로그 소개 글의 게시 확인까지 기본 계획에 포함합니다. 사용자가 가이드만 공개하도록 범위를 정하면 그 범위를 따릅니다. 단순 작성·형식 정비 요청 자체를 게시 승인으로 확대하지 않습니다.

## 시작할 때 정할 것

자료 유형·독자·범위·관련 가이드와 실습, 검증 환경, 공개할 저장소, 블로그 글의 범위와 URL, 소셜 초안 필요 여부를 정합니다.
작업 기록에 가이드 공개와 블로그 게시의 승인 범위를 각각 남깁니다. 이미 받은 승인은 이어 사용하며 재확인을 반복하지 않습니다. 새로 필요한 승인이 있다면 원고·그림·검증 결과·배포 대상이 준비된 뒤 구체적인 결과를 제시합니다.

## 단계와 완료 증거

| 단계 | 해야 할 일 | 완료로 판단할 증거 |
| --- | --- | --- |
| 1. 작성 | 표준·템플릿으로 원고, 표지, 개념 SVG, 실행 자료와 출처 작성 | 각 자료의 필수 파일과 학습 경로 |
| 2. 검토 | 사실·범위·사용자 입장·실행·시각·링크 확인, 지적 처분 | 검증 기록과 해결/수용한 잔여 사항 |
| 3. 가이드 공개 | 승인된 PR을 병합하고 공개 파일·이미지·탐색 확인 | 병합 commit/PR, 익명 접근되는 최종 URL |
| 4. 블로그 작성 | 공개 자료의 문제·핵심 개념·구성·시작점·검증 한계 소개 | 읽을 수 있는 원고, 대표 이미지와 핵심 SVG |
| 5. 블로그 게시 | 기존 글/slug 확인, 사이트 형식과 검토 계약 준수, build·배포 | 성공한 배포와 실제 글·이미지·가이드 링크 |
| 6. 소셜 초안 | 요청한 채널에 맞는 독립적인 소개문과 링크 작성 | 사용자가 복사할 완성 문장, 선택적 첨부 파일 |
| 7. 마무리 | 단계별 URL과 검증, 남은 작업 기록 | 가이드/블로그/소셜 각각의 정확한 상태 |

블로그까지 포함한 작업은 가이드 PR 병합만으로 완료 처리하지 않습니다. 사이트 배포 성공만으로도 끝내지 않고 최종 URL의 제목·본문·이미지·대표 metadata·가이드 링크를 확인합니다. 검색엔진 색인은 배포 완료 증거와 구분합니다.

## 블로그 글의 구조

1. 독자가 겪는 구체적인 문제와 이 자료가 필요한 이유.
2. 중심 질문과 첫 개념도. 원문에 없는 효과·사용 실적을 덧붙이지 않음.
3. 다루는 내용과 가이드·튜토리얼·실습의 역할. 자료마다 직접 링크를 제공.
4. 누구에게 맞고 어디서 시작할지, 필요한 환경과 검증 한계.
5. 다음 행동과 관련 자료. 업데이트·정정은 사이트의 기존 이력 형식을 따름.

가이드 전문을 블로그에 중복 복사하지 않습니다. 기존 소개 글이 있는 시리즈의 형식 정비만으로 새 글을 만들지 않습니다. 기존 글을 갱신할 이유가 있으면 그 변경을 설명합니다. 새 글인지 기존 글 갱신인지 공개 전에 확정하고 동일 slug의 중복 게시를 막습니다.

사이트의 실제 archetype·front matter·언어·시리즈·footer·배포 방식을 읽습니다. 지원하지 않는 metadata나 새로운 시리즈·공지 채널을 임의로 추가하지 않습니다. 독립 검토 조건이 있으면 검토자를 구분하고, 사용자가 생략을 승인한 경우에는 그 범위를 기록합니다. 작업 기록과 미검토 초안은 공개 저장소에 넣지 않습니다.

## 소셜은 선택적 수동 게시용 초안

`social: none` 또는 `social: draft`를 선택합니다. `draft`라면 채널과 글의 목적을 먼저 정합니다. 필요한 설명이 없는 짧은 링크 광고로 줄이지 않고 중심 내용 하나가 글 안에서 이해되게 씁니다.

- 완성된 게시 문장과 검증한 가이드/블로그 링크를 둡니다. 가이드가 여러 편이면 필요한 링크를 모두 제공합니다.
- 사용자 경험이나 성과를 지어내지 않고 원문의 한계를 보존합니다.
- 첨부가 필요하면 실제 사용 가능한 파일과 대체 텍스트를 함께 둡니다.
- 계정에 자동 게시하거나 메시지·Discussion 공지를 보내지 않습니다. 초안 완료와 실제 게시를 구분합니다.

## 재개와 실패

작업 기록에는 `guide`, `blog`, `social` 상태, 실제 URL, 승인 범위, 마지막 검증과 다음 행동을 각각 적습니다. 중단되면 마지막 성공 단계부터 재개합니다. 이미 발행한 글을 새로 생성하거나 반복 게시하지 않습니다. 접근 권한·연결 문제로 진행하지 못하면 준비한 결과를 보존하고 남은 단계를 정확히 보고합니다.
