# 자료 작성·정비 안내

Learnstead의 가이드·튜토리얼·실습을 작성하거나 수정하는 작업자와 AI agent를 위한 진입점입니다. 학습 자료를 찾는 독자는 [학습 자료 목록](../README.md)을 이용하세요.

## 작업 전에 읽을 문서

아래 순서로 확인하고, 필요한 단계의 상세 절차는 해당 문서를 따릅니다.

1. [작성 원칙](AUTHORING.md): 대상 독자, 설명 순서, 용어, 출처와 확인 범위.
2. [문서 구조](STRUCTURE.md): 자료 소개·본문·지원 문서, 상하 탐색과 하단 구분선.
3. [복사 템플릿](templates/README.md): 가이드·튜토리얼·실습, 표지와 첫 개념 SVG, 블로그·소셜 초안.
4. [그림 기준](VISUALS.md): Learnstead 표지의 스타일·배경색, 첫 개념도, 렌더와 판독 확인.
5. [검증 원칙](VALIDATION.md): 문서·링크·그림 검사와 실제 실행 검증, 확인하지 않은 범위의 기록.
6. [발행 절차](PUBLISHING.md): 가이드 공개 확인 → 블로그 소개 글 → 선택적 소셜 초안 → 결과 기록.

## 독자 안내와 작업자 안내

루트 README와 각 학습 자료의 본문은 독자가 자료를 고르고 배우는 데 필요한 내용을 담습니다. 작성·정비·발행 절차는 이 안내와 연결된 문서에서 관리합니다. 학습자에게 필요한 준비물·실행 명령·성공 판정·주의 사항은 학습 자료에 그대로 둡니다.

AI agent가 루트 README를 수정할 때는 소스의 작성자 안내 참조를 유지하세요. 참조 경로가 바뀌면 이 안내와 실제 진입점의 링크를 함께 수정합니다. 렌더된 README에 유지관리 절차를 다시 추가하지 않습니다.

## 기존 자료를 고칠 때

현재 공개된 파일을 기준으로 필요한 부분을 수정하고, 과거 초안으로 덮어쓰지 않습니다. 자료의 순서와 파일 목록은 [문서 목록](content-index.json)에서 확인합니다. 독자에게 영향을 주는 변경은 자료별 변경 기록에, 저장소 구조와 작성 정책의 변경은 루트 변경 기록에 남깁니다.

형식 검사 통과와 실제 실행 성공, PR 병합과 공개 반영 확인은 서로 다른 단계입니다. 각 단계의 확인 방법과 게시 승인 범위는 [검증](VALIDATION.md)과 [발행 절차](PUBLISHING.md)를 따릅니다.
