## 2026-09-07 보강 검증

- 가이드·실습의 단정적 설명을 보정하고 전달 입력의 경계와 전체 토큰 비용을 분리했습니다. `workers`는 코드가 작업을 고정하는 fan-out/fan-in임을 명시했습니다.
- 기존 모델 실행값은 2026-08-30·2026-09-06 기록을 유지합니다. 이번에는 모델 실험을 다시 실행하지 않았으며, 그림의 과거 수치를 본문의 해당 과제에 맞췄습니다.
- `labs/`에서 `python3 -m unittest discover -p 'test_*.py' -v`: 14개 통과. 동시 집계, 진행 중 호출의 예산 초과와 후속 호출 차단, 사용량 누락, 배치 입력·종료 코드, 라우터·평가 JSON, 반복 중단, 패턴별 초기화를 검사했습니다. 고정 응답을 사용하며 실제 모델 품질·SDK/서버 호환성의 검증은 아닙니다.
- Python 3.10 문법 호환 검사·bytecode 컴파일 통과. Markdown 22개 GFM 렌더 후 코드 밖 리터럴 `**` 0건, SVG 7종 lint 0 error·0 warning 및 Chrome 2× 렌더·시각 확인, `git diff --check` 통과.
- 두 팩을 공개 저장소 레이아웃에 임시 배치한 validator 결과: 기존 hero 이미지 4건 누락으로 전체 FAIL. 그 외 링크·형식 문제는 보고되지 않았습니다. 공개 발행 완료를 의미하지 않습니다.
- 토큰 예산은 응답 후 보고된 사용량을 기준으로 다음 호출을 막습니다. 이미 진행 중인 호출은 초과할 수 있고, 단일 프로세스 밖의 요청은 집계하지 않습니다. 사용량 누락 시 예산 활성화 상태에서는 중단합니다.
