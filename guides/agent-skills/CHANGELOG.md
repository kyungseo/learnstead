**AI Agent에게 일을 가르치는 법 — Agent Skills 기초** 가이드의 독자 대상 내용과 검증 범위를 기록합니다.

## 2026-09-13 — 문구와 설명 정비

- 어색한 문장과 오해하기 쉬운 비유를 다듬고, 조건·관찰·해석을 구분했습니다. 본문과 그림의 설명도 함께 확인했습니다.
- 기존 실행 환경·결과는 당시 기록으로 유지했습니다. 이번 정비는 모델이나 실행 도구 전 경로의 재검증을 뜻하지 않습니다.

## 2026-09-13 — 문서 형식 표준 적용

- 소개·본문·출처·검증·변경 기록의 상하 탐색과 하단 구분선을 공통 형식으로 맞췄습니다. 본문의 실행 명령과 기존 검증 날짜는 유지했습니다.

## 2026-09-03 — 초판

- 모델·런타임·도구의 관계부터 Skill의 역할, `SKILL.md` 구조, 선택과 호출, 여러 도구에서 재사용하는 방법까지 한 흐름으로 정리했습니다.
- slash command·rule·hook·subagent·MCP·plugin의 차이를 트리거·로드 시점·내용물·실행 주체로 비교합니다.
- Claude Code와 Codex의 현재 공식 Skill 경로와 실행 결과를 구분하고, Gemini CLI와 Cursor는 문서로 확인한 범위를 표시했습니다.
- 공개 전 확인할 경로·Secret·라이선스·출처 경계와 발견·로드·준수 단계의 실패 진단법을 담았습니다.
- 회의록을 액션 아이템으로 바꾸는 Skill 워크숍과 연결했습니다.
