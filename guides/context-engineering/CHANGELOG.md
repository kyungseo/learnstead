# 변경 기록

## 2026-09-03 — 초판

- Context Engineering을 지시문 하나의 작성법이 아니라 정보의 선택·배치·회수·유지·폐기를 다루는 흐름으로 설명합니다.
- Local LLM의 컨텍스트 한계, 앱의 대화 조립, RAG의 근거 검색, Skill의 절차, MCP의 도구 결과가 모델에 들어오는 지점을 연결했습니다.
- 항상 읽히는 진입 지시문과 조건부로 불러오는 규칙·Skill, local memory, 작업 압축 뒤 남겨야 할 정보를 구분합니다.
- Claude Code와 Codex에서 지시문의 크기·위치·형태가 규칙 준수에 미친 결과를 조건과 표본 한계와 함께 기록했습니다.
- 같은 실험을 직접 재현하는 지시문 예산 실습을 연결했습니다.
