## 2026-09-13 — 실습 관찰값과 학습 순서 보완

- 개념·튜토리얼·실습의 이동 경로와 예시를 맞추고, 실행 위치·초기화·재시작 설명을 보완했습니다.
- 검증 도구가 예상과 실제 관찰값을 출력하고 JSON에 남기도록 바꿨습니다. 실습 표는 이번 실행에서 나온 값으로 채울 수 있게 안내했습니다.
- 기존 검증 기록은 유지하고, 출력 기능 추가 후의 로컬 재검증은 검증 기록에 별도로 남깁니다.

## 2026-09-13 — 예시 소개와 개념 설명 순서 보완

- 스터디 신청 앱이 무엇인지 먼저 소개하고, 화면에 보이는 신청과 실제 저장의 차이를 구체적인 상황으로 설명했습니다.
- DB·테이블·문서·API 등의 뜻을 예시와 함께 설명하고, 사용자·모임·신청을 나누는 이유와 접근 권한 설명을 보완했습니다.
- 개념만 읽는 경로와 앱이 있을 때 해 볼 확인 활동을 구분했습니다. 실행 코드와 기존 검증 결과는 변경하지 않았습니다.

## 2026-09-13 — 프롬프트와 동작 설명 정리

- 프롬프트와 실제 동작을 구체적으로 설명하도록 문구를 다듬었습니다. 변경된 제목의 기존 링크는 유지하고, 명령·실험 결과는 그대로 두었습니다.

## 2026-09-13 — 확인 범위 설명 개선

- 검토 지침처럼 읽히던 문장을 실제로 확인한 내용과 확인하지 않은 환경·조건을 설명하는 문장으로 다듬었습니다. 기존 실행 결과와 검증 범위는 유지했습니다.

## 2026-09-13 — 문구와 설명 정비

- 어색한 문장과 오해하기 쉬운 비유를 다듬고, 조건·관찰·해석을 구분했습니다. 본문과 그림의 설명도 함께 확인했습니다.
- 기존 실행 환경·결과는 당시 기록으로 유지했습니다. 이번 정비는 모델이나 실행 도구 전 경로의 재검증을 뜻하지 않습니다.

## 2026-09-13 — 문서 형식 표준 적용

- 소개·본문·출처·검증·변경 기록의 상하 탐색과 하단 구분선을 공통 형식으로 맞췄습니다. 본문의 실행 명령과 기존 검증 날짜는 유지했습니다.

## 2026-09-13 — 대표 일러스트 통일

- 표지를 Learnstead의 손그림과 가로 비율에 맞추고 Git 가이드의 아이보리 종이 배경을 적용했습니다. 루트 카드와 시작 페이지에서 같은 WebP를 사용합니다.

## 2026-09-13 — 초판

- 비개발자가 AI와 만든 앱의 저장 위치·구조·권한·변경·복구를 이해하는 가이드 9장과 용어집을 제공합니다.
- SQLite·PostgreSQL·MySQL·MongoDB·Cloud Firestore를 비교하고 DBMS와 플랫폼의 역할을 구분합니다.
- 스터디 신청 앱을 기준으로 튜토리얼·실패 실습·데이터 관리 카드를 연결합니다.
- 제품 기능의 문서 확인과 실제 실행 자료의 검증 범위를 구분합니다.

## 다시 확인할 때

Supabase 키·RLS·CLI·백업 동작, 호스팅의 파일 지속성, DB 주요 버전, Firestore 과금·접근 규칙이 바뀌면 해당 본문과 출처를 다시 확인합니다. 요금제나 무료 한도는 이 문서에 고정 수치로 보장하지 않습니다.
