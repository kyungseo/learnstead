## 문서 확인 · 2026-09-13

[SOURCES.md](SOURCES.md)에 기록한 공식 문서를 열어 본문에서 사용한 주장과 범위를 대조했습니다. 확인 대상은 DB 선택 기준, 제약조건·트랜잭션, Supabase 키·RLS·migration·백업, 문서 DB 모델과 Firestore 권한·과금, SQL injection 예방, 인덱스·페이지 처리입니다.

제품 문서 확인은 제품의 설치·실행 검증을 뜻하지 않습니다. PostgreSQL `current` 문서는 확인 당시 18 문서를 가리켰으며, 실제 로컬 실행 버전은 아래의 실행 자료에 별도로 기록합니다.

## 예시의 성격

- 본문의 SQL·JSON은 구조를 읽는 설명 예입니다. 운영 DB에 적용하는 완성 migration이 아닙니다.
- 모임·사용자·신청 사례와 실패 상황은 가상 교육용 설계입니다. 실제 AI 도구의 실패율이나 실제 사용자 사고를 관측한 기록이 아닙니다.
- 데이터 관리 카드는 독자 작성 양식이며 검증 결과를 미리 채우지 않았습니다.
- 본문만으로 클라우드 운영, 모든 DBMS의 동일 동작, 보안 적합성, 성능·비용을 보장하지 않습니다.

## 실행 근거

실행 가능한 기준 앱과 고정 입력 실습은 별도 자료에 포함합니다. 사용한 OS·도구 버전·명령·정상 및 실패 결과·복구 범위는 각 자료의 기록이 기준입니다.

- [신청 앱 튜토리얼 검증 기록](../../tutorials/study-signup-db/VALIDATION.md)
- [DB 안전 실습 검증 기록](../../labs/database-safety/VALIDATION.md)

## 미검증 범위

이 가이드의 비교 대상으로 소개한 MySQL·MongoDB·Cloud Firestore의 전체 설치·운영 경로, 클라우드 Supabase 프로젝트의 운영, 실제 결제·실제 개인정보 처리, 대규모 부하와 장애 복구는 실행 검증 범위에 포함하지 않습니다. Windows 실행 여부는 실행 자료가 실제 확인한 환경을 따릅니다.
