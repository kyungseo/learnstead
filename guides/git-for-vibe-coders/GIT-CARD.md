# 내 프로젝트 Git 카드

프로젝트마다 "지금 Git이 어떤 상태인지"를 한 장에 적어 두는 양식입니다. 특히 **원격 복사본과 Secret 파일 처리는** 사고가 난 뒤에
찾으면 늦습니다.

← [가이드 README](README.md) · 다음 → [01 버전 관리란](01-what-is-version-control.md)

---

## 기록 원칙

- API 키, 비밀번호, 토큰의 **실제 값은 적지 않습니다.** "어디에 있는지"만 적습니다.
- "잘 되고 있음" 대신 실제 명령 결과(브랜치 이름, 원격 주소, 마지막 커밋)를 적습니다.
- 컴퓨터를 옮기거나 사람이 늘어날 때 이 카드를 먼저 갱신합니다.

## 복사해서 쓰는 template

```md
# Git 카드 — <프로젝트 이름>

## Save — 저장 지점

- git 관리 시작일:
- 기본 브랜치 이름: (main / master)
- 커밋 습관: (AI에게 큰 작업 시키기 전 / 하루 끝 / 기능 단위)
- 최근 커밋 3개:

## Branch — 갈래

- 전략: (트렁크 기반 / main만 사용)
- 지금 살아 있는 브랜치와 각각의 목적:
- 오래된 브랜치(1주 이상):

## Worktree — 병렬 작업 폴더

- 연결된 worktree와 담당 branch:
- 각 worktree를 쓰는 사람 또는 AI 세션:
- 정리 전에 확인할 미커밋 변경:

## Share — 공유

- 원격 저장소: (없음 / GitHub 주소)
- 공개 범위: (Private / Public)
- 마지막 push 시점:
- 함께 쓰는 사람:
- 첫 Public 전환 또는 다음 version release 계획: (없음 / Assess 필요 / 준비 중)

## Secret — 비밀 관리

- .gitignore에 등록한 것:
- 비밀값이 실제로 들어 있는 파일과 위치:
- 이 값들이 커밋된 적이 있는가: (없음 / 있었고 키 교체함 / 확인 안 함)

## 한계와 다음 조치

- 아직 안 한 것:
- 다음에 할 것:
```

## 가장 짧은 예시

이 가이드의 실습 저장소를 적은 예시입니다. `[실행 검증 · 2026-08-23]`

| 항목 | 기록 |
| --- | --- |
| Save | 2026-08-23 시작 · main · AI 작업 전 커밋 습관 · 최근: "푸터 추가", "오타 수정", "첫 저장" |
| Branch·Worktree | 트렁크 기반 · try-blue(폐기), try-green(병합 완료) · 추가 worktree 없음 |
| Share | 원격 없음 (로컬 실습) |
| Secret | .gitignore에 `.env`, `secret-config.txt` 등록 · 커밋된 적 없음 |
| 다음 | GitHub Private 저장소를 만들어 commit 기록의 원격 복사본 추가 |
