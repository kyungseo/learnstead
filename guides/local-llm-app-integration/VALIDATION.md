## 오프라인 논리 점검 (2026-08-24)

모델을 호출하지 않는 부분만 작성 환경에서 확인했습니다.

| 확인 항목 | 결과 |
| --- | --- |
| `calculate("(15+5)*2")` | `40` |
| `calculate("1/0")` | `오류: 0으로 나눌 수 없습니다` |
| `calculate("__import__('os').system('ls')")` | `오류: 계산할 수 없는 식입니다 (허용되지 않은 식: Call…)` — 함수 호출 노드 거부 |
| `list_docs()` | `["공지.md", "회의실-예약.md", "휴가-규정.md"]` |
| `read_doc("휴가-규정.md")` | 본문 반환 |
| `read_doc("../secret/비밀-메모.md")` | `오류: 허용되지 않은 경로: … (docs/ 밖)` |
| `read_doc("../secret/비밀-메모.md", allow_fixture_secret=True)` | 가짜 fixture 본문 반환 |
| `read_doc("../secret/다른파일.md", allow_fixture_secret=True)` | `오류: 허용되지 않은 경로` — 예외가 fixture 하나로 제한됨 |
| `read_doc("../agent_readonly.py")` | `오류: 허용되지 않은 경로` — Markdown 이외 파일 접근 거부 |
| `calculate("9**999999")` | `오류: … 지수는 정수이며 절댓값 12 이하` — 자원 고갈 입력 거부 |
| `read_doc("없는문서.md")` | `오류: 문서가 없습니다: 없는문서.md` |
| `search_docs("이월")` | 휴가-규정.md의 해당 줄 1건 |

이 결과는 도구 구현의 경계가 의도대로 동작함을 보입니다. 모델의 시도 여부는 위 실행 결과 표가 근거입니다.

## 실행하지 않은 경로를 읽는 법

위 표는 한 장비·한 모델 조합의 실행 결과이며, 특히 08의 "시도 여부"는 모델에 따라 크게 다릅니다. 04 §2.3의 context 창 변경은
아직 실행하지 않았습니다. 재현 가능한 issue를 만들려면 다음을 기록합니다.

- OS, Python 버전, `openai` 버전, Ollama 버전
- 모델 태그와 ID(`ollama list`), `ollama show`의 Capabilities, `ollama ps`의 CONTEXT
- 실행한 명령(플래그 포함)과 **도구 호출 로그 전체**
- 답변 원문과 판정 결과(08은 시도 여부·막은 겹)

API key, 내부 hostname, 개인 경로는 공개 issue에 넣지 않습니다.
