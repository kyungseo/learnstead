**내 문서와 대화하는 AI 이해하기 — RAG와 Graph의** 독자 대상 내용과 검증 범위 변화를 기록합니다.

## 2026-09-13 — 문구와 설명 정비

- 어색한 문장과 오해하기 쉬운 비유를 다듬고, 조건·관찰·해석을 구분했습니다. 본문과 그림의 설명도 함께 확인했습니다.
- 기존 실행 환경·결과는 당시 기록으로 유지했습니다. 이번 정비는 모델이나 실행 도구 전 경로의 재검증을 뜻하지 않습니다.
- 임베딩 접두어·late chunking 설명, 권한 필터의 적용 시점, SVG의 점수 예시와 토큰 합계를 바로잡았습니다.

## 2026-09-13 — 문서 형식 표준 적용

- 대표 표지의 제목을 한 줄의 `Learnstead : 짧은 제목` 형식으로 정리하고 Git 가이드의 아이보리 종이 배경에 맞췄습니다.
- 소개·본문·출처·검증·변경 기록의 상하 탐색과 하단 구분선을 공통 형식으로 맞췄습니다. 본문의 실행 명령과 기존 검증 날짜는 유지했습니다.

## 2026-08-23 — 초안

- RAG·Graph 생태계를 파이프라인의 일곱 자리로 정리하고, 기술 셋·도구·프레임워크를 자리별로 소개했습니다.
- LLM이 내 문서를 모르는 이유와 RAG·Long Context·Fine-tuning의 선택 기준을 담았습니다.
- 색인 시점·질의 시점 파이프라인, 임베딩·벡터 검색·vector store, 청킹·hybrid·reranker, 근거 고정 프롬프트를 설명했습니다.
- 가상의 사내 규정 4편과 Python 스크립트로 Local RAG를 만드는 실습(07), 검색 누락·잘못된 조각·관련 없는 문서·근거 없는
  답변 네 실패를 재현·판정하는 실습(08)을 제공했습니다.
- 그래프 기초·지식 그래프·graph database와 GraphRAG(원형·변형·선택 규칙), NetworkX 기반 최소 GraphRAG 실습(10 §5)을 담았습니다.
- 개인 RAG와 기업 RAG 파이프라인 아키텍처를 비교하고 권한 필터·평가를 강조했습니다.
- 실습 전 경로(07 Local RAG·Chroma, 08 네 시나리오, 10 GraphRAG)를 Apple Silicon Mac의 Ollama(`bge-m3`·`gemma3:4b`)에서 실행
  검증하고, 재현되지 않은 시나리오(①·④의 규칙 제거)와 예상 밖의 실패(단어 겹침으로 인한 환각, 트리플 오추출)를 본문에 그대로 기록했습니다.
- Index → Ask → Prove 흐름과 RAG 구성 카드를 추가했습니다.

## 2026-08-30 — Learnstead 첫 공개 준비

- 한 묶음이던 12문서를 가이드(이 자료, 01~10), 튜토리얼(내 문서에 답하는 Local RAG 만들기), 실습(RAG는 왜 틀리는가) 세 자료로
  나눴습니다. 실습 07·08과 GraphRAG 실습(구 10 §5)은 튜토리얼·실습으로 옮기고, 그래프 기초·GraphRAG·기업 비교·용어집을 07~10으로 다시 번호를 매겼습니다.
- 임베디드 graph database로 소개하던 Kuzu를 제거하고 2025-10 upstream 개발 중단 사실을 01에 적었습니다.
- 04 §2 점수 구간표를 "감각"이 아니라 실측(정답 0.63~0.73, 회색 0.50~0.62, 무관 0.50 이하)으로 다시 썼습니다.
- 03 §3 진단 플로우에 "불완전 답변"(근거는 맞는데 일부만 씀) 분기를 추가했습니다.
- 06 §3에 context 초과 잘림의 감지 신호(서버 로그 `truncating input prompt`)를 추가했습니다.
- "Python 60줄" 표현을 튜토리얼의 `rag_skeleton.py`(핵심 함수 60줄 남짓) 기준으로 맞추고, 식별자 예시를 `EQ-2291`로 통일했습니다.
- 한국어 강조 표기 직후 조사가 붙던 곳을 GFM renderer에서 깨지지 않게 고쳤습니다.
- 최신 Ollama context 동작과 GraphRAG 도구 상태를 공식 자료로 다시 확인하고, 제품·성능을 단정하던 표현을 검증 범위에 맞게 고쳤습니다.
- 개념 ASCII·Mermaid를 SVG 또는 단계 설명으로 바꾸고, 그래프 관계 방향과 선택 기준을 명확히 했습니다.
- 골든셋 측정을 질문 성공률과 구절 recall로 분리하고, 점수 하한 계산을 필수 구절별로 바로잡았습니다.
- 개인·기업 RAG 비교 도식의 흐름 카드를 좌우 16px 여백 안에 균등하게 배치해 마지막 카드와 외곽 프레임이 겹치지 않게 했습니다.
