# 변경 기록

**AI와 함께 만들기 — 바이브 코딩에서 Agentic Engineering으로**(가이드)의 독자 대상 내용 변화를 기록합니다.

## 2026-09-01 — 초판

- 바이브 코딩의 유래에서 출발해, AI에게 구현을 맡기면서도 사람이 목표·범위·검증·품질을 책임지는 작업 흐름을 설명합니다.
- Frontend·Backend/API·Database의 역할과 AI builder·BaaS·hosting·harness가 대신하는 범위를 큰 그림으로 정리했습니다.
- 목표와 성공 조건 정하기, 되돌릴 지점 남기기, 한 번에 하나씩 지시하기, 다섯 가지 확인, 막힘에서 빠져나오기, 새 대화로 인계하기를 한 흐름으로 구성했습니다.
- 공개 전에 Secret·실행 환경·입력·남은 흔적·license를 점검하고, GitHub 저장소를 공개할 때 `github-release-guide`로 추가 확인하는 방법을 담았습니다.
- 전문 code review·security·성능 검증이 필요한 범위와 돈·개인정보·인증·법·안전처럼 사람의 판단에서 멈춰야 하는 경계를 명시했습니다.
- 고정된 할 일 앱 세 판으로 다섯 가지 확인을 연습하는 실습과 프로젝트 카드를 연결했습니다.
