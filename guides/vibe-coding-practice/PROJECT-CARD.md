만드는 것·확인 방법·막힌 지점을 한 장에 남기는 양식입니다. 대화는 사라져도 이 카드는 남습니다.

## 기록 원칙

- **API 키·비밀번호의 실제 값은 적지 않습니다.** "어디에 있는지"만 적습니다.
- "잘 되고 있음" 대신 **눌러 본 결과를** 적습니다.
- **"아직 확인 안 함"을 적는 것이** 절반입니다.
- 막혔다가 풀렸으면 **무엇이 원인이었는지** 한 줄 남깁니다 — 다음에 같은 자리에서 또 막히지 않게.

## 가장 짧은 예시

| 항목 | 기록 |
| --- | --- |
| Decide | 나 혼자 / 할 일 관리 / 입력→추가→체크 / 3개 넣고 새로고침해도 남으면 성공 / 로그인·공유 안 함 |
| 구조·실행 환경 | HTML·CSS·JavaScript / 별도 Backend 없음 / 브라우저 저장소 / hosting 미정 |
| 안전망 | git ✓ · 마지막 잘 되던 커밋 `e4f5g6h` · `.env` 무시 중 |
| Slice | "클릭하면 취소선" — 2개 중 하나만 클릭해 확인 → 성공 |
| Check | ① ✓ ② 빈칸 제출 시 무반응(요청 예정) ③ ✓ ④ 삭제 기능 ✓ ⑤ app.js만 변경 |
