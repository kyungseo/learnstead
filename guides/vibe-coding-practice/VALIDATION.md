## 인용한 명령의 검증 출처

이 가이드에 나오는 Git 명령은 [Git 가이드](../git-for-vibe-coders/README.md)에서 임시 저장소를 만들어 실행 검증한
것입니다. 그 기록은 [해당 VALIDATION](../git-for-vibe-coders/VALIDATION.md)에 있습니다. 특히:

- `git restore 파일` — 지목한 파일만 복원되고 다른 파일은 남는 것을 확인
- `git revert` — 취소 커밋이 쌓이고 원 커밋이 유지되는 것을 확인
- `git reset --hard` — **커밋되지 않은 작업이 영구 삭제되는 것을 실제로 확인** (이 가이드 02·06·10의 ⛔ 표기 근거)
- `git ls-files`·`git log --all --name-only --format=` — 현재 추적 파일과 history의 파일명 확인. Secret 부재를 증명하는 명령은 아님

## 확인하지 않은 것

- 특정 AI 코딩·개발·배포 도구의 계정별 화면·배포 절차·자동 커밋 동작
- 컨텍스트 창이 찼을 때 각 도구가 실제로 무엇을 하는지의 직접 재현
- 이 가이드의 작업 방식을 따랐을 때의 정량적 효과
