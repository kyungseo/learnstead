나눠 맡기고 검증하기 자료의 독자 대상 변경을 기록합니다.

## 2026-09-13 — 프롬프트와 동작 설명 정리

- 프롬프트와 실제 동작을 구체적으로 설명하도록 문구를 다듬었습니다. 변경된 제목의 기존 링크는 유지하고, 명령·실험 결과는 그대로 두었습니다.

## 2026-09-13 — 문구와 설명 정비

- 어색한 문장과 오해하기 쉬운 비유를 다듬고, 조건·관찰·해석을 구분했습니다. 본문과 그림의 설명도 함께 확인했습니다.
- 기존 실행 환경·결과는 당시 기록으로 유지했습니다. 이번 정비는 모델이나 실행 도구 전 경로의 재검증을 뜻하지 않습니다.

## 2026-09-13 — 문서 형식 표준 적용

- 소개·본문·출처·검증·변경 기록의 상하 탐색과 하단 구분선을 공통 형식으로 맞췄습니다. 본문의 실행 명령과 기존 검증 날짜는 유지했습니다.
- 대표 표지의 종이 배경을 Git 가이드의 옅은 아이보리 기준에 맞췄습니다.

## 2026-09-07 — 경과 시간 표기 통일

- 실습 본문·기록표·검증 기록의 시간 지표를 “총 경과 시간”으로 통일하고, 도입부에 측정 구간의 시작부터 끝까지 걸린 시간이라는 뜻을 설명했습니다.
- 측정값·명령·코드 식별자와 검토 턴 한정·최종 통합 제외 등 측정 범위는 유지했습니다.

## 2026-09-07 — 문서 탐색 링크 통일

- README 상·하단에도 첫 장으로 이동하는 시작 링크를 추가했습니다.
- 각 장의 상·하단에 이전 장·목차·다음 장 이동 링크를 동일하게 배치했습니다. 첫 장과 마지막 장은 읽는 순서에 맞는 이동 경로를 제공합니다.

## 2026-09-07 — 초심자를 위한 설명 보완

- 추상적인 “나누기”를 작업 위임·역할 구분·입력 자료 제한·작업 폴더 분리 등 실제 동작에 맞게 풀어 썼습니다. 대상 독자, 학습 목표, 용어 설명과 결과 해석을 함께 다듬었습니다.
- 입력량·시간 기록에서 확인한 사실과 원인 추정을 구분하고, 기존 실행값·명령·코드는 유지했습니다.

## 2026-09-07 — 초판

- 결함을 심은 가계부 코드와 고정 시나리오로 기준선·위임·병렬·새 컨텍스트 검토를 비교합니다.
- Claude Code 또는 Codex 단독 실행, 결과 덮어쓰기 방지, 실행 실패·통합 상태·미측정 사용량 표시와 회귀 검사 11개를 포함합니다.
- 대표 일러스트와 읽기 순서, 출처·실행 기록·미검증 범위를 함께 제공합니다.
