**다섯 가지 확인 — 코드를 읽지 않고 세 판을 판정하기의** 독자 대상 내용과 검증 범위 변화를 기록합니다.

## 2026-09-13 — 문서 형식 표준 적용

- 소개·본문·출처·검증·변경 기록의 상하 탐색과 하단 구분선을 공통 형식으로 맞췄습니다. 본문의 실행 명령과 기존 검증 날짜는 유지했습니다.
- 대표 표지의 종이 배경을 Git 가이드의 옅은 아이보리 기준에 맞췄습니다.

## 2026-09-01 — 초판

- 가이드 "AI와 함께 만들기" 05장의 다섯 가지 확인을 고정된 예제로 연습하는 실습을 신설했습니다.
- 할 일 앱 세 판(v1 잘 되던 상태 / v2 새로고침 소실 / v3 삭제 깨짐·빈칸 안내 없음·요청하지 않은 변경)을 정적 파일로 제공하고, 판별
  기대 결과와 각 실패 뒤의 다음 행동, `git restore .` 원상복구 절차를 담았습니다.
- 요청하지 않은 파일이 `git status`에 그대로 드러나도록 `debug-notes.txt`로 제공해 ⑤ 확인을 재현할 수 있게 했습니다.
- 세 판을 브라우저에서 실제로 열어 다섯 확인을 수행한 기록을 실었습니다.
