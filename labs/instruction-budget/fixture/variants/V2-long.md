# textkit

작은 텍스트 유틸리티 패키지. `src/textkit/`에 모듈, `tests/`에 pytest.

## 빌드와 배포

- Docker 이미지는 `python:3.12-slim`을 베이스로 한다.
- CI는 GitHub Actions의 `ci.yml` 하나만 유지한다.
- 배포 태그는 `v<major>.<minor>.<patch>` 형식이다.
- 릴리스 노트는 태그마다 GitHub Release에 붙인다.
- 빌드 아티팩트는 `dist/`에만 두고 커밋하지 않는다.
- 의존성은 `pyproject.toml`의 `[project.dependencies]`에만 적는다.
- 캐시 키는 lock 파일 해시로 만든다.
- 프리뷰 환경은 PR마다 하나씩 만든다.
- 롤백은 이전 태그 재배포로 한다.
- 배포 창은 평일 10~16시다.

빌드와 배포에 관한 배경: 이 절의 규칙은 지난 분기 회고에서 정리한 것이며, 예외가 필요하면 PR 설명에 이유를 적고 리뷰어 승인을 받는다. 자동화 가능한 항목은 CI로 옮기는 것을 우선한다.

운영 중 이 규칙을 어겨 장애가 난 사례가 두 번 있었고, 그 뒤 팀 규칙으로 승격했다. 규칙을 바꾸려면 ADR을 먼저 올리고 팀 회의에서 합의한다. 임시 예외는 이슈에 기한과 함께 적는다.

새로 합류한 사람은 이 절을 첫 주에 읽고 담당자에게 질문을 남긴다. 규칙이 코드와 어긋나는 곳을 발견하면 코드를 고치는 PR과 함께 이 문서를 갱신한다.

이 절의 항목은 자동화 도구(린터·CI 검사)와 겹치는 것이 있어도 문서에 남겨 둔다. 도구가 잡지 못하는 의도와 예외 조건을 사람이 읽을 수 있어야 하기 때문이다. 항목을 지울 때는 대체 수단을 같이 적는다.

## 데이터베이스

- 테이블 이름은 복수형 snake_case다.
- 마이그레이션은 Alembic으로 관리하고 revision 메시지는 영어로 쓴다.
- 외래 키에는 항상 인덱스를 둔다.
- 새로 만드는 `.py` 파일의 **첫 줄은** `# owner: platform-team` 주석이다.
- soft delete는 `deleted_at` 컬럼으로 표현한다.
- 시각은 UTC로 저장하고 표시 시점에 변환한다.
- N+1 질의를 발견하면 `selectinload`로 고친다.
- 읽기 복제본은 보고서 질의에만 쓴다.
- 트랜잭션 범위는 서비스 계층에서 정한다.
- 대량 갱신은 배치 크기 1,000으로 나눈다.
- 스키마 변경은 하위 호환을 먼저 배포한다.

## API 설계

- 엔드포인트는 명사 복수형(`/users`)이다.
- 오류 응답은 `{"error": {"code", "message"}}` 형식이다.
- 페이지네이션은 `cursor` 방식이다.
- 버전은 URL 경로(`/v1/`)에 둔다.
- 요청 검증은 pydantic 모델로 한다.
- OpenAPI 문서의 summary는 한 문장이다.
- 필드 이름은 snake_case다.
- 날짜는 ISO 8601 문자열이다.
- 삭제는 204를 돌려준다.
- rate limit 헤더를 항상 붙인다.

## 프런트엔드

- 컴포넌트 파일은 PascalCase다.
- 상태 관리는 zustand만 쓴다.
- CSS는 Tailwind 유틸리티만 쓰고 커스텀 클래스를 만들지 않는다.
- 모든 함수에 한국어 docstring을 쓴다. 첫 줄은 한 문장으로 끝낸다.
- 이미지는 `next/image`로만 넣는다.
- 폼 검증은 zod 스키마를 재사용한다.
- 접근성: 모든 버튼에 `aria-label`.
- 번들 크기 예산은 250KB다.
- i18n 키는 점 표기법이다.
- 테스트는 Testing Library로 쓴다.
- 스토리북 스토리를 컴포넌트마다 둔다.

## 로깅과 관측

- 로그는 JSON 한 줄 형식이다.
- 로그 레벨은 DEBUG/INFO/WARNING/ERROR 네 가지만 쓴다.
- 요청 ID를 모든 로그에 넣는다.
- 모든 함수 인자와 반환값에 타입 힌트를 붙인다.
- 메트릭 이름은 `<서비스>_<지표>_<단위>` 형식이다.
- 알림은 5분 평균 기준으로 건다.
- 예외는 로그에 스택 트레이스를 포함한다.
- 샘플링 비율은 10%다.
- PII는 로그에서 마스킹한다.
- 대시보드는 서비스당 하나다.
- 알림 채널은 심각도별로 나눈다.
