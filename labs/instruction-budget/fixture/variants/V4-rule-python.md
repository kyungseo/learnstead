1. 새로 만드는 `.py` 파일의 **첫 줄은** `# owner: platform-team` 주석이다.
2. 모든 함수에 한국어 docstring을 쓴다. 첫 줄은 한 문장으로 끝낸다.
3. 모든 함수 인자와 반환값에 타입 힌트를 붙인다.
4. 테스트는 `tests/test_<모듈>.py`에 두고 함수 이름은 `test_<함수>_<경우>` 형식이다.
5. 기능을 추가하면 `CHANGELOG.md`의 `## [Unreleased]` 아래에 `- <기능> 추가` 한 줄을 넣는다.
