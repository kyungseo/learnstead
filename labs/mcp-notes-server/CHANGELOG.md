**노트 MCP 서버 — 만들고, 꽂고, 깨뜨리기** 실습의 독자 대상 내용과 검증 범위를 기록합니다.

## 2026-09-13 — 문구와 설명 정비

- 어색한 문장과 오해하기 쉬운 비유를 다듬고, 조건·관찰·해석을 구분했습니다. 본문과 그림의 설명도 함께 확인했습니다.
- 기존 실행 환경·결과는 당시 기록으로 유지했습니다. 이번 정비는 모델이나 실행 도구 전 경로의 재검증을 뜻하지 않습니다.

## 2026-09-13 — 문서 형식 표준 적용

- 소개·본문·출처·검증·변경 기록의 상하 탐색과 하단 구분선을 공통 형식으로 맞췄습니다. 본문의 실행 명령과 기존 검증 날짜는 유지했습니다.
- 대표 표지의 종이 배경을 Git 가이드의 옅은 아이보리 기준에 맞췄습니다.

## 2026-09-03 — 초판

- Python으로 작은 읽기 전용 노트 서버를 만들고 SDK client로 도구 목록과 호출 결과를 먼저 확인합니다.
- 같은 서버를 Claude Code와 Codex에 연결하고 실제 도구 호출 로그를 관측합니다.
- 경로 탈출, 등록되지 않은 쓰기, 거짓 annotation, 노트에 섞인 주입 지시문, stdout 오염을 재현합니다.
- 프로젝트 상대 경로와 환경 변수를 사용한 설정 예제를 제공하고, 실행용 설정과 로그는 git 추적에서 제외합니다.
- Skill이 절차를 맡고 MCP가 능력을 제공하는 조합을 마지막 단계에서 실행합니다.
