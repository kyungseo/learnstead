**Skill 워크숍 — 하나를 만들어 두 도구에서 관측하기** 실습의 독자 대상 내용과 검증 범위를 기록합니다.

## 2026-09-13 — 문구와 설명 정비

- 어색한 문장과 오해하기 쉬운 비유를 다듬고, 조건·관찰·해석을 구분했습니다. 본문과 그림의 설명도 함께 확인했습니다.
- 기존 실행 환경·결과는 당시 기록으로 유지했습니다. 이번 정비는 모델이나 실행 도구 전 경로의 재검증을 뜻하지 않습니다.

## 2026-09-13 — 문서 형식 표준 적용

- 소개·본문·출처·검증·변경 기록의 상하 탐색과 하단 구분선을 공통 형식으로 맞췄습니다. 본문의 실행 명령과 기존 검증 날짜는 유지했습니다.
- 대표 표지의 종이 배경을 Git 가이드의 옅은 아이보리 기준에 맞췄습니다.

## 2026-09-03 — 초판

- 회의록을 액션 아이템으로 바꾸는 Skill을 만들어 Claude Code와 Codex에서 명시 호출과 자동 호출을 관측합니다.
- description을 넓혔을 때의 과호출, 도구별 발견 경로, 같은 이름의 Skill 충돌을 직접 확인합니다.
- 같은 절차를 Skill로 제공한 경우와 프롬프트에 붙인 경우를 반복 실행하고 판정 스크립트로 비교합니다.
- 실험이 만든 파일만 정리하며, 비어 있지 않은 대상·잘못된 label·경로 이동을 거부하도록 fixture를 구성했습니다.
