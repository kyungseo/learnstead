**RAG는 왜 틀리는가의** 독자 대상 내용과 검증 범위 변화를 기록합니다.

## 2026-09-13 — 문구와 설명 정비

- 어색한 문장과 오해하기 쉬운 비유를 다듬고, 조건·관찰·해석을 구분했습니다. 본문과 그림의 설명도 함께 확인했습니다.
- 기존 실행 환경·결과는 당시 기록으로 유지했습니다. 이번 정비는 모델이나 실행 도구 전 경로의 재검증을 뜻하지 않습니다.
- Graph 실습의 실제 두 문서 배치, 임베딩 호출 여부, hybrid에서도 dense 하한을 쓰는 동작을 설명에 반영했습니다.

## 2026-09-13 — 문서 형식 표준 적용

- 대표 표지의 제목을 한 줄의 `Learnstead : 짧은 제목` 형식으로 정리하고 Git 가이드의 아이보리 종이 배경에 맞췄습니다.
- 소개·본문·출처·검증·변경 기록의 상하 탐색과 하단 구분선을 공통 형식으로 맞췄습니다. 본문의 실행 명령과 기존 검증 날짜는 유지했습니다.
- 답변의 잘못된 인용 예시를 코드로 표시해 문서 내 이동 링크로 오인되지 않게 했습니다.

## 2026-08-31 — 재실행 변동성과 입력 검사 보강

- 같은 모델과 `temperature=0`에서도 GraphRAG의 답변·인용 형태가 달라질 수 있음을 두 번째 실행 결과로 확인하고, 문자열이 아닌
  트리플·근거·원문으로 판정하도록 설명을 보강했습니다.
- `--top-k`는 1 이상, `--hops`는 0 이상만 허용하고 `--chunk`는 `paragraph` 또는 양의 정수인 `fixed:N`만 받도록 했습니다.

## 2026-08-30 — Learnstead 첫 공개

- 2026-08-23 초안 가이드 "내 문서를 LLM에 연결하기"의 08 실습과 GraphRAG 실습(10 §5)을 독립 실습 자료로 분리했습니다.
- 판정 규칙에 세 번째 축(답이 근거를 다 썼는가)을 더해 **②′ 불완전 답변을** 정의하고, 단어 겹침 환각을 **③′로** 승격했습니다.
- GraphRAG 실습의 문서를 4편으로 나누고 같은 단어를 쓰는 공지 문서를 추가해, 벡터 RAG가 top-k 3에서 실패하는 negative case를 만들었습니다.
  홉 수가 모자랄 때의 환각과 정답인데 인용이 틀리는 장면을 기록했습니다.
- 골든셋 20문항과 `recall.py`를 추가했습니다. 조각 번호가 아니라 정답 구절로 판정해 청킹을 바꿔도 비교할 수 있게 했고, 질문 성공률과
  구절 recall, 점수 하한이 들어갈 틈(정답 최저 vs 없는 질문 최고)을 함께 보고합니다.
- GraphRAG 근거 사실에 출처 파일을 표시해 트리플과 원문을 바로 대조할 수 있게 했습니다.
- 전 시나리오를 Ollama 0.33.0에서 다시 실행해 출력을 갱신했습니다.
