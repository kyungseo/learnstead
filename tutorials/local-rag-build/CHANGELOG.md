# 변경 기록

**내 문서에 답하는 Local RAG 만들기의** 독자 대상 내용과 검증 범위 변화를 기록합니다.

## 2026-08-31 — CLI 입력 검사 보강

- `--top-k`에 1 미만의 값을 넣으면 모델을 호출하기 전에 이해하기 쉬운 오류 메시지로 중단하도록 했습니다.

## 2026-08-30 — Learnstead 첫 공개

- 2026-08-23 초안 가이드 "내 문서를 LLM에 연결하기"의 07 실습을 독립 튜토리얼로 분리했습니다.
- 핵심 함수 다섯 개, 60줄 남짓의 `rag_skeleton.py`를 새로 두었습니다. 실패 재현용 플래그가 있는 판은 실습 자료로 옮겼습니다.
- `rag_chroma.py`를 Chroma 1.x의 `configuration` 방식으로 고치고, 튜토리얼 전 경로를 Ollama 0.33.0에서 다시 실행해 출력을 갱신했습니다.
- "근거는 맞는데 덜 쓴 답"을 판정 습관의 첫 사례로 소개하고 실습 ②′로 연결했습니다.
- 최소 예제의 0 벡터 코사인 계산을 안전하게 처리하고, RAG의 최소 동작 구조와 운영용 확장을 구분했습니다.
