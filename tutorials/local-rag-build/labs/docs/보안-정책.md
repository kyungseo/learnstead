# 정보보안 정책

## 1. 계정과 비밀번호

비밀번호는 12자 이상으로 영문·숫자·특수문자를 조합하며 90일마다 변경한다. 다른 사람과 계정을 공유하지 않는다.

## 2. 저장 매체

승인되지 않은 USB 저장 장치의 사용을 금지한다. 외부로 자료를 반출할 때는 정보보호팀의 사전 승인을 받고 암호화한다.

## 3. 보안 교육

전 직원은 연 1회 정보보안 교육을 이수해야 한다. 교육을 이수하지 않으면 다음 해 연차 신청 시스템 접근이 제한될 수 있다.

## 4. 사고 신고

보안 사고를 인지하면 즉시 정보보호팀에 신고한다. 신고를 지연하여 피해가 확대된 경우 책임을 물을 수 있다.
