# 회의실 예약 안내

## 1. 회의실 종류

본사 5층에는 소회의실 A·B(4인), 중회의실 C(8인), 대회의실 D(20인)가 있다. 대회의실 D에는 화상 회의 장비가 설치되어 있다.

## 2. 예약 방법

회의실은 사내 포털의 예약 메뉴에서 예약한다. 한 번에 최대 2시간까지 예약할 수 있으며, 2시간을 초과하는 회의는 총무팀에 별도로 신청한다. 예약은 사용일 기준 14일 전부터 가능하다.

## 3. 취소와 노쇼

예약 시작 후 15분 이내에 입실하지 않으면 예약이 자동으로 취소된다. 한 달에 3회 이상 노쇼가 발생한 사용자는 다음 달 예약이 제한된다.

## 4. 사용 수칙

사용 후에는 화이트보드를 지우고 의자를 정돈한다. 음식물 반입은 대회의실 D에서만 허용된다.
