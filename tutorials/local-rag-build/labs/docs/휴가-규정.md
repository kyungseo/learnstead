# 휴가 규정

## 1. 연차 발생

입사 후 1년 미만인 직원은 1개월 개근 시 1일의 연차가 발생한다. 1년 이상 근속한 직원은 매년 1월 1일에 15일의 연차가 발생하며, 3년 이상 근속 시 2년마다 1일씩 가산한다.

## 2. 연차 신청

연차는 사용일 3일 전까지 인사 시스템에서 신청하고 팀장의 승인을 받아야 한다. 반차는 오전(09:00~13:00)과 오후(14:00~18:00)로 나누어 사용할 수 있으며 0.5일로 계산한다.

## 3. 연차 이월

사용하지 않은 연차는 다음 해 3월 말까지 이월해 사용할 수 있다. 3월 말까지 사용하지 않은 이월 연차는 소멸하며 금전으로 보상하지 않는다. 이월 한도는 직급에 따라 다르다.

이월 한도
- 일반 직원: 최대 5일
- 관리자(팀장 이상): 최대 10일

## 4. 경조 휴가

본인 결혼 5일, 자녀 결혼 1일, 배우자 출산 10일, 부모·배우자·자녀 사망 5일의 경조 휴가를 별도로 부여한다. 경조 휴가는 사유 발생일로부터 30일 이내에 사용해야 한다.
